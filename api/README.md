Kaynak derlemesi (veritabanına bağlanmaz):

```powershell
.\dotnet.cmd restore WinFormsApp2.sln --locked-mode
.\dotnet.cmd build WinFormsApp2.sln -c Release --no-restore -p:TreatWarningsAsErrors=true
```

Sunucuyu başlatmak ayrıca sunucuya özel bağlantı profili, uyumlu şema, Windows hizmet hesabı ve güvenilir TLS sertifikası gerektirir. Bu değişiklik sırasında sunucu başlatılmadı ve canlı veritabanı kullanılmadı. Denemeler kullanıcı isteğiyle atlandı.
